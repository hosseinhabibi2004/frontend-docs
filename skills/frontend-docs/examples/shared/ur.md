# گریڈینٹ ڈیسنٹ کا تعارف

گریڈینٹ ڈیسنٹ ایک قابلِ تفرق فنکشن $f:\mathbb{R}^n\to\mathbb{R}$ کو گریڈینٹ کی مخالف سمت میں قدم اٹھا کر کم کرتا ہے۔

::: abstract
ہم اپ ڈیٹ کا اصول $x_{k+1}=x_k-\eta\nabla f(x_k)$ اخذ کرتے ہیں۔
:::

## اپ ڈیٹ کا اصول

$$
x_{k+1} = x_k - \eta\,\nabla f(x_k)
$$

::: tip
$\eta < 2/L$ منتخب کریں تاکہ الگورتھم منتشر نہ ہو۔
:::

```python
def step(x, grad, eta=0.1):
    return x - eta * grad(x)
```
