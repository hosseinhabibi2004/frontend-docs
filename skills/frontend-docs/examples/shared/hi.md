# ग्रेडिएंट डिसेंट का परिचय

ग्रेडिएंट डिसेंट किसी अवकलनीय फलन $f:\mathbb{R}^n\to\mathbb{R}$ को ग्रेडिएंट की विपरीत दिशा में बार-बार कदम बढ़ाकर न्यूनतम करता है।

::: abstract
हम अपडेट नियम $x_{k+1}=x_k-\eta\nabla f(x_k)$ निकालते हैं।
:::

## अपडेट नियम

$$
x_{k+1} = x_k - \eta\,\nabla f(x_k)
$$

::: tip
$\eta < 2/L$ चुनें ताकि विचलन न हो।
:::

```python
def step(x, grad, eta=0.1):
    return x - eta * grad(x)
```
