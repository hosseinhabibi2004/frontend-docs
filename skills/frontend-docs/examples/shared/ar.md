# مدخل إلى النزول التدرّجي

يقلّل النزول التدرّجي دالة قابلة للاشتقاق $f:\mathbb{R}^n\to\mathbb{R}$ بخطوات متتالية عكس اتجاه التدرّج. وهو أساس التعلّم الآلي الحديث.

::: abstract
نشتق قاعدة التحديث $x_{k+1}=x_k-\eta\nabla f(x_k)$ ونثبت التقارب الخطي للدوال المحدبة بقوة ونعرض تنفيذًا مرجعيًّا قصيرًا.
:::

## قاعدة التحديث

لطول خطوة $\eta>0$ يكون التكرار:

$$
x_{k+1} = x_k - \eta\,\nabla f(x_k), \qquad k = 0,1,2,\dots
$$

::: definition
تُسمّى الدالة $f$ **محدبة بقوة $\mu$** إذا تحقق لكل $x,y$:

$$f(y)\ge f(x)+\nabla f(x)^\top (y-x)+\tfrac{\mu}{2}\lVert y-x\rVert^2 .$$
:::

::: theorem
إذا كانت $f$ محدبة بقوة وتدرّجها $L$-ليبشيتزي وكان $\eta\le 1/L$ فإن
$\lVert x_k-x^\star\rVert^2 \le (1-\eta\mu)^k\,\lVert x_0-x^\star\rVert^2$ .
:::

::: proof
وسّع $\lVert x_{k+1}-x^\star\rVert^2$ واستعمل التحدب القوي ثم بسّط بالشرط $\eta\le 1/L$.
:::

## التنفيذ المرجعي

```python
import numpy as np

def gradient_descent(grad, x0, eta=0.1, steps=200):
    x = np.asarray(x0, dtype=float)
    for _ in range(steps):
        x = x - eta * grad(x)
    return x
```

اختر `eta` أصغر من $2/L$؛ الخطوات الأكبر تتباعد[^1].

| الطريقة | كلفة الخطوة | المعدل |
|---|---|---|
| النزول التدرّجي | $O(n)$ | خطي |
| نيوتن | $O(n^3)$ | تربيعي |

::: tip
ارسم $f(x_k)$ بمقياس لوغاريتمي: الخط المستقيم يعني تقاربًا خطيًّا.
:::

## تمارين

::: exercise
بيّن أن أفضل خطوة ثابتة للدالة $f(x)=\tfrac12 x^\top A x$ هي $\eta = 2/(\lambda_{\min}+\lambda_{\max})$.
:::

[^1]: $L$ ثابت ليبشيتز للتدرّج $\nabla f$.
