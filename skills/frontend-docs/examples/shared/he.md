# מבוא לירידת גרדיאנט

ירידת גרדיאנט ממזערת פונקציה גזירה $f:\mathbb{R}^n\to\mathbb{R}$ על ידי צעדים חוזרים נגד כיוון הגרדיאנט.

::: abstract
נפתח את כלל העדכון $x_{k+1}=x_k-\eta\nabla f(x_k)$ ונציג מימוש קצר.
:::

## כלל העדכון

$$
x_{k+1} = x_k - \eta\,\nabla f(x_k)
$$

::: tip
בחרו $\eta < 2/L$ כדי למנוע התבדרות.
:::

```python
def step(x, grad, eta=0.1):
    return x - eta * grad(x)
```
