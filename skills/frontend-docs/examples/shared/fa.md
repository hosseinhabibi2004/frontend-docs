# مقدمه‌ای بر کاهش گرادیان

کاهش گرادیان با برداشتن گام‌های پیاپی در خلاف جهت گرادیان، تابع مشتق‌پذیر $f:\mathbb{R}^n\to\mathbb{R}$ را کمینه می‌کند. این روش پایهٔ یادگیری ماشین امروزی است، از رگرسیون خطی تا شبکه‌های عمیق.

::: abstract
قاعدهٔ به‌روزرسانی $x_{k+1}=x_k-\eta\nabla f(x_k)$ را به‌دست می‌آوریم، همگرایی خطی برای توابع به‌شدت محدب را اثبات می‌کنیم و یک پیاده‌سازی کوتاه نشان می‌دهیم.
:::

## قاعدهٔ به‌روزرسانی

برای طول گام $\eta>0$ تکرار به این صورت است:

$$
x_{k+1} = x_k - \eta\,\nabla f(x_k), \qquad k = 0,1,2,\dots
$$

::: definition
تابع $f$ را **$\mu$-به‌شدت محدب** می‌گوییم هرگاه برای هر $x,y$ داشته باشیم:

$$f(y)\ge f(x)+\nabla f(x)^\top (y-x)+\tfrac{\mu}{2}\lVert y-x\rVert^2 .$$
:::

::: theorem
اگر $f$ به‌شدت محدب با گرادیان $L$-لیپشیتز باشد و $\eta\le 1/L$، آنگاه
$\lVert x_k-x^\star\rVert^2 \le (1-\eta\mu)^k\,\lVert x_0-x^\star\rVert^2$ .
:::

::: proof
عبارت $\lVert x_{k+1}-x^\star\rVert^2$ را بسط دهید و از تحدب قوی استفاده کنید؛ سپس با شرط $\eta\le 1/L$ ساده کنید.
:::

## پیاده‌سازی مرجع

```python
import numpy as np

def gradient_descent(grad, x0, eta=0.1, steps=200):
    """Plain fixed-step gradient descent."""
    x = np.asarray(x0, dtype=float)
    for _ in range(steps):
        x = x - eta * grad(x)
    return x

print(gradient_descent(lambda x: x, [4.0, -2.0]))
```

مقدار `eta` را کمتر از $2/L$ انتخاب کنید؛ گام‌های بزرگ‌تر واگرا می‌شوند[^1].

| روش | هزینهٔ هر گام | نرخ |
|---|---|---|
| کاهش گرادیان | $O(n)$ | خطی |
| نیوتن | $O(n^3)$ | مرتبهٔ دوم |
| تکانه | $O(n)$ | شتاب‌دار |

::: tip
نمودار $f(x_k)$ را در مقیاس لگاریتمی بکشید: خط راست یعنی همگرایی خطی.
:::

## تمرین‌ها

::: exercise
نشان دهید برای $f(x)=\tfrac12 x^\top A x$ با $A\succ 0$ بهترین گام ثابت برابر $\eta = 2/(\lambda_{\min}+\lambda_{\max})$ است.
:::

::: answer
مقدار $\max_i \lvert 1-\eta\lambda_i\rvert$ را کمینه کنید؛ مقدار بهینه دو مقدار ویژهٔ کران را برابر می‌کند.
:::

[^1]: $L$ ثابت لیپشیتز $\nabla f$ است.
