# ترکیب متن فارسی با فرمول و لاتین

مقدار گام (که با $\eta$ نشان داده می‌شود) باید کمتر از $2/L$ باشد؛ در غیر این صورت تکرار واگرا می‌شود (برای نمونه $x_{k+1}=x_k-\eta\nabla f(x_k)$).

اگر تابع $f$ به‌شدت محدب باشد، آن‌گاه $\lVert x_k-x^\star\rVert^2 \le (1-\eta\mu)^k\,\lVert x_0-x^\star\rVert^2$ برقرار است و همگرایی خطی داریم.

کتابخانه‌های (React) و (Python 3.12) را نصب کنید؛ سپس `pip install numpy` را اجرا کنید. تابع `f(x, y)` مقدار (x + y) را برمی‌گرداند.

سرعت انتقال ۱۰ MB/s و دما 36.6°C است. نشانی: https://example.com/a-b-c؟ بله.

از Python استفاده کنید. نسخهٔ (3.12) توصیه می‌شود: «Hello, world!» را چاپ می‌کند.

::: definition
تابع $f$ را **به‌شدت محدب** می‌گوییم هرگاه برای هر $x,y$ داشته باشیم $f(y)\ge f(x)+\nabla f(x)^\top (y-x)+\tfrac{\mu}{2}\lVert y-x\rVert^2$ و $\mu>0$.
:::

- گام $\eta=0.1$ (پیش‌فرض)
- نرخ $O(1/k)$ برای حالت محدب
- مقدار `eta` در تابع `gradient_descent(grad, x0)`

| روش | هزینه | نرخ |
|---|---|---|
| گرادیان | $O(n)$ | $(1-\mu/L)^k$ |
| نیوتن (Newton) | $O(n^3)$ | مرتبهٔ دوم |
