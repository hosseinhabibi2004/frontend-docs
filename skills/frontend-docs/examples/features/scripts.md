# Scripts and languages

Every block below is set in its own language: the engine switches font, line-height, justification, emphasis style and quotation marks per `lang`.

::: lang en

## English

Typography is the craft of making written language **legible** and *beautiful*. Numbers read 1234567890 and $E=mc^2$.

:::

::: lang ru

## Русский

Типографика — это искусство делать письменную речь **читаемой** и *красивой*. Числа: 1234567890.

:::

::: lang el

## Ελληνικά

Η τυπογραφία είναι η τέχνη να κάνουμε τον γραπτό λόγο **ευανάγνωστο** και *όμορφο*. Αριθμοί: 1234567890.

:::

::: lang vi

## Tiếng Việt

Kiểu chữ là nghệ thuật làm cho ngôn ngữ viết **dễ đọc** và *đẹp mắt*. Số: 1234567890.

:::

::: lang fa

## فارسی

حروف‌چینی هنر **خوانا** و *زیبا* کردن زبان نوشتاری است. اعداد: 1234567890 و $E=mc^2$.

:::

::: lang ar

الطباعة فنّ جعل اللغة المكتوبة **مقروءة** و*جميلة*. الأرقام: 1234567890.

:::

::: lang ur

## اردو

ٹائپوگرافی تحریری زبان کو **پڑھنے کے قابل** اور *خوبصورت* بنانے کا فن ہے۔

:::

::: lang ps

## پښتو

ټایپوګرافي د لیکل شوې ژبې د **لوستلو وړ** او *ښکلې* کولو هنر دی.

:::

::: lang ckb

تایپۆگرافی هونەری **خوێنراو** و *جوانکردنی* زمانی نووسراوە.

:::

::: lang he

## עברית

טיפוגרפיה היא אמנות הפיכת השפה הכתובה ל**קריאה** ו*יפה*. מספרים: 1234567890.

:::

::: lang hi

## हिन्दी

टाइपोग्राफ़ी लिखित भाषा को **पठनीय** और *सुंदर* बनाने की कला है। संख्याएँ: 1234567890.

:::

::: lang bn

## বাংলা

টাইপোগ্রাফি হলো লিখিত ভাষাকে **পাঠযোগ্য** ও *সুন্দর* করে তোলার শিল্প।

:::

::: lang ta

## தமிழ்

அச்சுக்கலை என்பது எழுத்து மொழியை **படிக்கவும்** *அழகாகவும்* ஆக்கும் கலை.

:::

::: lang te

## తెలుగు

టైపోగ్రఫీ అనేది వ్రాత భాషను **చదవడానికి సులభంగా** మరియు *అందంగా* మార్చే కళ.

:::

::: lang gu

## ગુજરાતી

ટાઇપોગ્રાફી એ લેખિત ભાષાને **વાંચવા યોગ્ય** અને *સુંદર* બનાવવાની કળા છે.

:::

::: lang pa

## ਪੰਜਾਬੀ

ਟਾਈਪੋਗ੍ਰਾਫੀ ਲਿਖਤੀ ਭਾਸ਼ਾ ਨੂੰ **ਪੜ੍ਹਨ ਯੋਗ** ਅਤੇ *ਸੋਹਣਾ* ਬਣਾਉਣ ਦੀ ਕਲਾ ਹੈ।

:::

::: lang kn

## ಕನ್ನಡ

ಮುದ್ರಣಕಲೆ ಲಿಖಿತ ಭಾಷೆಯನ್ನು **ಓದಲು ಸುಲಭ** ಮತ್ತು *ಸುಂದರವಾಗಿಸುವ* ಕಲೆ.

:::

::: lang ml

:::

::: lang th

:::
